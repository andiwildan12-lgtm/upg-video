# Motion Klinik Gigi

Skill ini menghasilkan **paket konsep video** (brief, storyboard, prompt) untuk konten klinik gigi.

> **Pembagian skill:** skill ini hanya untuk konsep/naskah cepat. Produksi dan render: UPG → skill `upg-video` (+ cabang), Ruma → `ruma-dental-video` + `produksi-video-klinik`. Aturan visual terkunci tiga akun (UPG, Ruma, GrowWith) ada di skill bersama `panduan-visual-terpadu`; kalau bertentangan, panduan itu dan skill brand yang menang. Skill bersama: salinan identik di repo `upg-video` dan `ruma-video` (dipindahkan dari repo Game-SOP, 20 Nov 2026). Outputnya harus bisa langsung diserahkan ke tim konten/editor, atau ditempel ke Canva / tools AI video tanpa diolah ulang.

## 1. Alur kerja

1. **Tangkap brief.** Kalau data kurang, JANGAN banyak bertanya. Isi pakai default (bagian 2), lalu tulis "Asumsi" di akhir output.
2. **Tentukan brand.** Pakai UPG Dental Care atau Ruma Dental (bagian 3). Tone keduanya beda, jangan dicampur.
3. **Pilih tujuan dan formula** (bagian 4).
4. **Tulis paket video** dengan format output (bagian 6).
5. **Cek kepatuhan iklan kesehatan** (bagian 7) sebelum final.
6. Kalau diminta, buatkan **prompt Canva / AI video** (bagian 8).

## 2. Default kalau brief kosong

| Item | Default |
|---|---|
| Platform | Instagram Reels + TikTok |
| Rasio | 9:16 (1080×1920) |
| Durasi | 15–30 detik |
| Bahasa | Indonesia santai-sopan, sapaan "kamu", boleh sentuhan Makassar ringan untuk UPG |
| Teks layar | Maks 6–8 kata per frame, font besar, area aman: kosongkan ±250 px atas, ±400 px bawah, ±120 px kanan |
| Subtitle | Selalu ada, maks 2 baris, 5–7 kata per baris |
| CTA | Sesuai funnel: TOFU follow/simpan, MOFU tanya di DM, BOFU reservasi WhatsApp (5 dtk terakhir: logo + 1 ajakan) |

## 3. Profil brand

### UPG Dental Care (Makassar)
- **Posisi:** klinik gigi terpercaya, volume pasien tinggi, cepat, terjangkau, tim lengkap.
- **Tone:** hangat, energik, dekat dengan warga, jelas, sedikit humor.
- **Visual:** cerah, ramai tapi rapi, potongan cepat (cut 1–2 detik), teks bold, banyak wajah tim/pasien (dengan izin).
- **Musik:** ikuti jalur di skill `upg-video` (MOTION tanpa musik; edukasi/rekaman boleh backsound berlisensi atau ElevenLabs Music). Jangan lagu trending tanpa lisensi.
- **Warna/font:** Oranye #FA7209, Krem #FFF7EF, teks #2A2A2A (teks di atas oranye selalu gelap), Nunito.
- **Kata kunci:** cepat ditangani, tim berpengalaman, harga transparan, jadwal fleksibel.

### Ruma Dental
- **Posisi:** premium, nyaman, clean, middle-high, pelayanan personal dan dapat dipercaya.
- **Tone:** tenang, elegan, meyakinkan, tidak jualan keras.
- **Visual:** warna netral/soft, banyak ruang kosong, gerakan kamera pelan (slow push-in, slide), transisi halus (fade/dissolve), detail interior dan alat yang rapi.
- **Warna/font:** Turquoise #28CDBD (blok, bukan warna teks), Mint White #E8F8F6, Deep Teal #354B49 untuk teks; Neue Montreal + Montserrat.
- **Musik:** ambient/lo-fi/piano lembut.
- **Kata kunci:** nyaman, tanpa terburu-buru, penjelasan jelas, personal. (Kata "steril" tidak dipakai sebagai klaim.)

### GrowWith (akun gabungan)
- TOFU saja: cerita orang-orang UPG/Ruma (Real Storytelling, POV, Reality Game). Tanpa promo, harga, WA, reservasi, lowongan. Detail di panduan visual terpadu.

> Data resmi (logo, WA, harga) ada di skill brand: `upg-video` + cabang, `ruma-dental-video`. Jangan mengarang kode warna, harga, atau nomor.

## 4. Tujuan → formula video

| Tujuan | Formula | Durasi |
|---|---|---|
| Edukasi (awareness) | Hook mitos/fakta → penjelasan 2–3 poin → tips → CTA lembut | 20–45 dtk |
| Promo layanan | Masalah pasien → solusi layanan → proses singkat → info/benefit → CTA booking | 15–30 dtk |
| Trust / behind the scene | Aktivitas tim → standar kerja (SOP, alat disiapkan) → wajah dokter → CTA | 15–30 dtk |
| Testimoni | Kutipan pasien (izin tertulis) → cerita singkat → suasana klinik → CTA | 20–40 dtk |
| Pengumuman | Info utama besar di detik 0–2 → detail → CTA | 7–15 dtk |
| Video TV ruang tunggu | Loop tanpa suara, teks besar, 1 pesan per slide | 30–60 dtk loop |

**Bank hook (3 detik pertama):**
- "Gusi berdarah waktu sikat gigi? Jangan dianggap sepele."
- "3 kebiasaan yang diam-diam merusak gigi kamu."
- "Takut ke dokter gigi? Ini yang sebenarnya terjadi di ruang praktik."
- "Scaling bikin gigi renggang? Mitos atau fakta?"
- "Behel itu bukan cuma soal rapi. Ini alasannya."
- "Anak susah diajak ke dokter gigi? Coba cara ini."

## 5. Aturan motion

- **Durasi video 15–60 dtk.** **Detik 0–3 wajib menahan scroll:** gerakan + teks hook besar, tanpa logo intro panjang.
- **Satu scene = satu pesan.** Ganti visual tiap 2–4 dtk (UPG boleh lebih cepat, Ruma lebih pelan).
- **Animasi teks:** pop/slide-in untuk UPG, fade/rise halus untuk Ruma. Hindari efek norak (spin, glitch berlebihan).
- **Logo:** kecil di sudut, atau end card 2 detik. Jangan menutupi wajah atau teks.
- **End card:** logo + CTA + nomor WA/handle + alamat singkat.
- **Visual klinis:** tidak ada darah, tidak ada close-up prosedur yang bikin ngeri. Pakai ilustrasi/animasi gigi 3D untuk menjelaskan prosedur.

## 6. Format output (wajib)

```
JUDUL KONTEN: ...
Brand: UPG Dental Care / Ruma Dental
Tujuan: ...   Platform: ...   Rasio: ...   Durasi: ...
Target penonton: ...
Pesan utama (1 kalimat): ...

STORYBOARD
| Scene | Detik | Visual & gerakan | Teks layar | Voice over / audio |
|---|---|---|---|---|
| 1 (Hook) | 0–3 | ... | ... | ... |
| 2 | 3–8 | ... | ... | ... |
| ... | | | | |
| End card | x–y | Logo + CTA | ... | ... |

MUSIK / SFX: ...
CAPTION POSTINGAN: (2–4 kalimat + CTA)
HASHTAG: 5–8 (campur lokal Makassar + topik)
KEBUTUHAN SYUTING: daftar shot yang harus diambil tim (talent, lokasi, properti)
CHECKLIST KEPATUHAN: ✔/✖ per poin bagian 7
ASUMSI (perlu divalidasi): ...
```

Kalau diminta beberapa ide, beri 3 opsi dulu (judul + hook + angle, masing-masing 2 baris). Storyboard lengkap dibuat untuk opsi yang dipilih.

## 7. Kepatuhan iklan fasilitas kesehatan (cek sebelum final)

- ✖ Klaim superlatif: "terbaik", "nomor 1", "paling murah", "dijamin", "100% tanpa sakit".
- ✖ Menjanjikan hasil pasti atau membandingkan dengan klinik lain.
- ✖ Foto before–after atau wajah pasien **tanpa izin tertulis** (informed consent publikasi).
- ✖ Data medis/identitas pasien terlihat di layar (rekam medis, nama di monitor).
- ✔ Klaim faktual & bisa dibuktikan ("dokter gigi spesialis ortodonti"). Hindari kata "steril" sebagai klaim.
- ✔ Konten klinis direview dokter sebelum tayang. Testimoni dan before-after wajib izin tertulis; contoh di storyboard pakai placeholder, bukan kutipan karangan.
- ✔ Promo harga harus jelas syarat dan periodenya. Pakai kalimat aman: "mulai dari", "S&K berlaku".
- ✔ Konten edukasi akurat secara klinis. Kalau ragu, tandai "[validasi drg]".

## 8. Prompt Canva / AI video

Kalau diminta prompt, buat per scene dengan pola:

```
[Rasio 9:16] [Gaya: [brand style]] Scene [n], [durasi] detik.
Visual: [subjek, aksi, lokasi, pencahayaan, sudut kamera, gerakan kamera].
Teks overlay: "[teks]", posisi [atas/tengah/bawah], animasi [jenis].
Warna: [warna brand]. Mood: [mood]. Hindari: darah, alat tajam close-up, teks kecil.
```

Untuk Canva: sebutkan juga **elemen** (ikon gigi, frame, sticker), **template** (Reels/Story), dan **transisi** antar halaman.
