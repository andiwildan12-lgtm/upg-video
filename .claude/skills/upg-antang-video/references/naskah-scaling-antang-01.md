# Naskah Iklan Promo Scaling — UPG Dental Care Antang (v2, 18 Nov 2026)

Status: **draf v2 (fokus konversi chat), menunggu OK Pak Dir.**
Konsep: **Promo Scaling Rp200.000 (normal Rp250–350 rb), kuota terbatas per hari (tanpa angka), tanpa batas jam.**
Keputusan Pak Dir: harga normal sama Hertasning (dicoret), kuota tidak ditulis angkanya, fakta medis OK, garansi dihapus.
Format: 9:16, ±50 dtk + kartu 3 dtk, motion 3D + footage Antang, narator Tio ("U-Pe-Ge"), tanpa musik, SFX.

## Strategi konversi (beda dari v1)
1. Hook fakta yang "menantang" kebiasaan penonton (sikat sekuat apa pun).
2. Masalah singkat & konkret (2 kalimat), langsung ke solusi — iklan promo tidak boleh lama di edukasi.
3. **Harga jangkar**: sebut harga normal dulu, baru harga promo → terasa hemat.
4. Proses jelas = menurunkan takut (dicek dulu, dokter gigi, alat getar).
5. **Kelangkaan jujur**: kuota terbatas tiap hari (tanpa angka).
6. **CTA spesifik**: klik tombol chat → ketik "SCALING" → admin bantu pilih jadwal. Langkah sekecil mungkin.
7. Lokasi di akhir sebagai pengingat, bukan pembuka.

[warmly] Selesai scaling, gigi terasa licin, napas lebih segar.
