## Batas
- Pengamatan ini berasal dari beberapa cuplikan visual di browser (oleh pihak lain sebelum skill dibuat). Ini **bukan** analisis lengkap audio dan transisi.
- **Jangan mengarang** easing, durasi gerak per frame, nama font, atau isi audio referensi.
- Link Instagram biasanya tidak bisa dibuka dari lingkungan ini (perlu login). Pakai catatan ini sebagai referensi terbatas. Minta file video **hanya** bila analisis detail benar-benar diperlukan. Bila file diberikan, frame bisa dipotong dengan ffmpeg untuk dianalisis.
- Isi materi ketenagakerjaan di HRDaily belum diaudit dan **tidak** boleh dijadikan fakta.
