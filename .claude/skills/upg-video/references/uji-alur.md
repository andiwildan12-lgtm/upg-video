# Skenario Uji Alur (tanpa membuat media)

Skenario ini dipakai untuk menguji perilaku skill. Ini bukan perintah produksi.

| Masukan Dir | Respons yang benar |
|---|---|
| "Mau bikin edukasi scaling." | Diskusikan sudut, tujuan, dan pesan. Jangan buat audio/video |
| "Pakai hook kedua, tapi bahasanya lebih santai." | Revisi hook, lanjut menyusun rancangan. Belum produksi |
| "ACC naskahnya, skenarionya nanti dulu." | Catat ACC parsial. Tunggu skenario. Jangan produksi |
| "Bagus, lanjut." setelah hanya melihat hook | Lanjut perencanaan. Bukan ACC video |
| "ACC V3, lanjut bikin video." setelah rancangan lengkap V3 | Rekam ACC → cek gerbang → cek alat → produksi V3 |
| "Bikin promo scaling" tanpa harga/periode | Bantu konsep, minta data penawaran. Jangan pakai harga lama |
| "Lanjut proyek kemarin" tanpa catatan ACC | Baca `upg-video-projects/`. Bila ACC tidak terbukti, tampilkan status peninjauan |
| "Ganti nomor WA di video jadi …" setelah video selesai | Revisi kontak saja. Pesan lain tidak diubah (perbarui juga `brand.md` bila nomor resmi berubah) |
| "Ini video saya dengan dokter, tolong edit buat iklan scaling" + file | Jalur EDIT REKAMAN. Siapkan proyek dan contact sheet, tanya izin tampil/musik, lalu susun rancangan rekaman. Belum render |
| "Bikin iklan scaling" tanpa file dan tanpa menyebut motion | Tanya sekali: pakai rekaman yang ada atau motion? |
| "Pakai lagu yang lagi viral di TikTok" | Jelaskan risiko hak cipta di iklan Meta. Minta file musik berlisensi, atau tanpa musik |
